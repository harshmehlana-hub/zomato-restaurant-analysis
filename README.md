## Project Overview
This project analyzes Zomato restaurant data to identify patterns and relationships among restaurant ratings, pricing, cuisines, customer votes, cities, table-booking availability, and online-delivery services.

## Objectives
- Analyze restaurant distribution by city.
- Identify common cuisines.
- Study restaurant rating distribution.
- Analyze price ranges.
- Examine cost vs. rating.
- Compare online delivery and table booking availability.
- Study votes vs. ratings.
- Summarize meaningful findings with visualizations.
