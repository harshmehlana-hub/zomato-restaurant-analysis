# Frequently Asked Questions

## What is the project about?
This project performs exploratory data analysis on Zomato restaurant data to identify patterns in restaurant locations, cuisines, ratings, pricing, customer votes, and service facilities.

## Why was this dataset selected?
The dataset contains a useful mix of numerical and categorical restaurant attributes, making it suitable for practicing data cleaning, exploratory analysis, and visualization.

## Which tools are used?
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook / Google Colab, and GitHub.

## What does the analysis cover?
The analysis covers restaurant counts by city, common cuisines, rating distribution, price ranges, cost versus rating, online delivery, table booking, votes versus ratings, and correlations among selected numerical variables.

## How are rating values of 0 handled?
A rating of 0 is treated as a not-rated value for rating-based analysis rather than as a zero-star restaurant rating.

## What is the main outcome?
The project converts the raw restaurant dataset into visual summaries and interpretable findings that describe patterns in the data.

## Is the analysis causal?
No. The project reports associations and patterns found in the dataset; correlation does not establish causation.
